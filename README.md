# CODE//VOID

### Problems Without Solutions.

> 50 extreme programming and computer-science challenges designed to push your problem-solving ability to the limit.

[🌐 Live Website](https://shivam-web-80.github.io/code-void/)

---

## 🧠 About

Most coding platforms teach you how to solve problems.

**CODE//VOID asks a different question:**

> **What happens when there is no solution waiting for you?**

CODE//VOID is a collection of 50 challenging programming problems covering algorithms, data structures, graph theory, mathematics, dynamic programming, systems, and more.

There are:

- No tutorials
- No hints
- No editorials
- No solutions
- No signup
- No accounts

**Only problems.**

Can you solve them?

## 🎮 How It Works

1. Open CODE//VOID.
2. Browse the challenges.
3. Search or filter by category/difficulty.
4. Pick a problem.
5. Read the problem carefully.
6. Try to solve it yourself.

That's it.

There is no solution waiting at the bottom.
